Graphs : 
    Graph is a collection of vertices + edges or nodes + connections.
    A---------B
    |         |
    |         |
    C---------D
    Vertices -> A B C D
    Edges -> A-B A-C C-D B-D
             
Pentagon
    • Google Maps -> location + road
    • Airline Network -> airport + flight
    • Social Network -> users + connections
    • Computer Lab -> computer + connections
    • Web -> pages + hyperlinks 

Types of Graphs: 
    • Undirected Graph -> connection works both the ways | Ex: Facebook friends
    • Directed Graph -> A->B is possible & B->A is neccessarily not possible | Ex: Instagram followers

Adjacency Matrix :
    A---------B
    |         |
    |         |
    C---------D
    An Adjacency matrix representsa graph using a 2D arrays.

    Matirx :
      A  B  C  D
    A 0  1  1  0
    B 1  0  0  1
    C 1  0  0  1
    D 0  1  1  0
    
    matrix[A][B] = 1 -> A & B are connected
    matrix[A][D] = 0 -> A & D are not connected

Adjacency List :
    Instead of creating a complete matrix we can store only the connected vertices.
  0 A---------B 1
    |         |
    |         |
  2 C---------D 3
    A -> B C       0 -> 1 2
    B -> A D       1 -> 0 2
    C -> A D       2 -> 0 3
    D -> B C       3 -> 1 2

Dense Graph = Many Connections
Sparse Graph = Few Connections

Dense Graph :
    • A graph is dense when the number of edges is close to the maximum possible number of edges.
    • For an undirected graph with v vertices [ maximum edges = (V(V-1)) / 2 ]

Sparse Graph :
    • A graph is sparse when the number of edges is much closer to the minimum possible number of edges

DFS(Depth First Search):
    • DFS explores one complete path before coming back and exploring another path
    Ex -> Maze :
        • Enter a path - keep going untill we cannot continue
        • Come back - try another path 
    Logic :
        1. Start froma vertex
        2. Mark it as visited
        3. Process it
        4. Visit every unvisited neighbour recursively
        5. Backtrack when no unvisited neighbour remains
    0-------1------     |          0          |    ________________            |        0
    |              \    |        /   \        |    |              |            |       / \
    |               3   |       2      1      |    0 --> 1 --> 3 --> 2 --> 4   |      1   2 
    |                   |      /        \     |                                |     /     \
    2-------4           |     4          3    |                                |    3       4

    DFS => Inorder, Preorder, Postorder 

    Ex:             ----> Java(1)
        Project(0) |        ----> Arrays(3)
                    ----> Python(2)
                            ----> Dictionaries(4)
